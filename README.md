# Proyecto Urban Lunch
## 1. Objetivo del proyecto
Probar el diseño y funcionalidad de la aplicación de pedido de comidas Urban Lunch, abarcando desde la selección del punto de recogida y la elección de platillos hasta la confirmación del envío del pedido.
## 2. Pasos para realizar las pruebas
1. Abrir la lista de comprobación de la hoja de cálculo.
2. Iniciar el emulador de Honor 8 en Android Studio.
3. Comprobar cada item de la lista de comprobación, comparando cada diseño con lo expuesto en Figma.
4. Redactar informes de errores en caso de ser necesario.
